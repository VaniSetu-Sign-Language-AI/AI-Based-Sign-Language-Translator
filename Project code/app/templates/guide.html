Collect · Train · Run

The complete workflow for VaniSetu — from gathering signs to a live translator. Run all commands from D:\mc0177 with your venv active.

1 · Collect signs

Option A — webcam, one custom sign, no menus (recommended). Show the sign clearly, vary angles and lighting.

python -m src.data.collect_landmarks --mode webcam --label HELLO --frames-per-class 150

Option B — webcam, interactive. Press A–Z/0–9 for quick signs, N to type any custom name (THANK YOU), Q to quit.

python -m src.data.collect_landmarks --mode webcam

Option C — existing photos. One folder per sign; any folder name becomes a label.

data\raw_images\HELLO\photo1.jpg, photo2.jpg, ...
python -m src.data.collect_landmarks --mode image

Verify what landed (aim for 120+ kept frames per sign):

python -c "import pandas as pd; df=pd.read_csv('data/landmarks.csv'); print(len(df),'frames'); print(df['label'].value_counts())"

2 · Train the model

Full run — required whenever labels change. Trains the CNN+LSTM backbone, then the RandomForest head, and writes the report consumed by the Metrics page.

python -m src.training.train --epochs 60 --batch-size 32

Fast path — only re-fits the forest when the label set is unchanged (e.g. tuning tree count):

python -m src.training.train --rf-only

Tune filters, LSTM units, dropout and trees in configs/config.yaml. If a sign scores poorly in the per-class table, collect more frames for it and retrain.

3 · Run the app

python app/app.py
